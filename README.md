# Retail Sales Analysis Dashboard

## Project Overview
An end-to-end retail sales analysis project using the Superstore dataset. The project explores sales, profit, orders, customers, regional performance, product performance, category performance, and yearly sales trends.

## Tools Used
- **Excel:** Data cleaning and pivot-table analysis
- **MySQL:** Data storage and SQL analysis
- **Power BI:** Interactive dashboard and visual reporting

## Dashboard Highlights
- Total Sales: **$2.30M**
- Total Profit: **$286.40K**
- Total Orders: **5,009**
- Total Customers: **793**
- Sales by region, category, and year
- Top 5 products by sales
- Profit by category
- Year, region, and category slicers

## Repository Files
- `retail_sales_analysis.sql` — SQL data preparation and analysis queries.
- `retail_sales_analysis.pbix` — Power BI report file (upload separately if not present).
- `superstore_cleaned.csv` — Cleaned Superstore dataset (upload separately if not present).
- `superstore_sales_analysis.xlsx` — Excel analysis and pivot tables (upload separately if not present).

## Dataset
The cleaned Superstore dataset contains 9,994 records. The analysis uses fields such as order date, ship date, sales, profit, customer, region, category, and product.

## How to Use
1. Open the SQL file in MySQL Workbench and run the analysis against the Superstore table.
2. Open the Excel workbook to review the cleaned data and pivot analysis.
3. Open the Power BI `.pbix` file in Power BI Desktop to explore the dashboard.
